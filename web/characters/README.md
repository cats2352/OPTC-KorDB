# 캐릭터 DB 화면 구조

- `index.html`: 캐릭터 목록과 상세 창의 기본 화면
- `filter-panel.html`: 필터 패널 UI만 모아 둔 파일
- `app.js`: 검색, 정렬, 페이지네이션, 카드와 상세 창 제어
- `character-data.js`: `units.js` 데이터 읽기와 이미지 경로 규칙
- `filter-panel.js`: 필터 패널 열기·닫기·선택 상태 제어
- `styles.css`: 캐릭터 DB 전용 스타일

새 캐릭터는 `../data/units.js`에 숫자 ID로 추가하면 목록에 자동 반영됩니다. `1234-1`처럼 하이픈이 포함된 파생 ID는 목록에서 제외됩니다.

단, 기본 ID 카드의 상세 창에서는 `1234-1`, `1234-2`처럼 연결된 형태 데이터를 탭으로 표시합니다. 파생 형태 전용 이미지가 없으면 기본 캐릭터 이미지를 사용합니다.
