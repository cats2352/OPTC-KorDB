# 캐릭터 데이터 폴더

`units.js`는 캐릭터 번호를 키로 사용하는 한국어 원본 데이터입니다. 예를 들어 `units["4324"]`에는 징베의 카드 및 상세 스탯 정보가 들어 있습니다.

`details.js`는 같은 번호를 키로 사용하는 한국어 능력 데이터입니다. 필살기, 선장·선원 효과, 잠재 능력, 서포트, 한계 돌파, 교체·VS·Rush 계열 효과를 담고 있습니다.

- 목록 카드: 번호, 이름, 속성, 타입, 등급, 코스트
- 상세 창: 콤보, 슬롯, 최대 레벨, 최대 경험치, 최소·최대 체력/공격력/회복력

목록은 `units.js`에 있는 모든 숫자 번호를 자동으로 사용합니다. 따라서 새 숫자 ID 데이터를 추가하면 카드 목록·검색·정렬·페이지 수에 자동 반영됩니다. `xxxx-1` 같은 파생 키는 목록과 썸네일 매칭에 사용하지 않습니다.

데이터를 갱신할 때는 같은 형식의 한국어 `units.js` 파일로 이 파일만 교체하면 됩니다. `null`·빈 값은 DB 화면에 표시되지 않고, `0`은 정상 값으로 표시됩니다.
